# FORGE 13 Native Preview

React Native 0.87 Android app built alongside the existing FORGE v12 PWA.

- Native Today / Train / Nutrition / Analytics / More
- Persistent AsyncStorage state
- Native workout logging
- Native nutrition logging
- Hall of Fame / performance surfaces
- Share Studio with device photo picker + Android share sheet
- YouTube Music hand-off
- v12 JSON backup import bridge
- Existing PWA remains untouched

Build output is produced by .github/workflows/forge13-android.yml.
